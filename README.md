# Banking AI Assistant

A professional AI assistant specialized in Banking Systems and Financial Services, utilizing RAG (Retrieval-Augmented Generation) and LangGraph for agentic capabilities.

## Features
- **RAG Pipeline**: Answers banking questions using local documents.
- **Agentic Tools**: Can browse the internet and save files.
- **Context Awareness**: Handles follow-up questions using chat history.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Set up `.env` with API keys.
3. Run the server: `python main.py`
